## Document envelope

Front matter opens and closes with `---`. A document that contains a directive must declare `azemark: 2`.

| Front matter field | Type or accepted values | Required |
| --- | --- | --- |
| `azemark` | `integer` | yes |
| `author` | `string-list` | no |
| `title` | `text` | no |
| `theme` | `text` | no |
| `outputs` | `string-list`: `html`, `svg`, `png`, `pdf` | no |
| `defaults` | `record` | no |
| `citation-style` | `enum`: `numeric`, `author-year` | no |

Directive fences are exactly `::::` at document level and `::` when nested. The header/body separator is `----`. Structural indentation is 2 spaces. Standalone structural comments start with `//`.

Document identifiers match `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$` and share one document-wide namespace.

## Reading the field tables

A path such as `x-axis.scale` means `scale` is nested under `x-axis`. A path such as `function.domain.min` starts with a record kind, then follows its nested fields. `required` applies inside that record or group, not to every Block of the directive.

The tables describe syntax. Semantic rules still apply. For example, a reference must resolve to a compatible earlier declaration, a logarithmic axis accepts only positive values, and a checked reaction must balance. The category guides explain those rules and show accepted Sources.
